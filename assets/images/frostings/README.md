# Frosting photos (frosting ON a brownie)

IMPORTANT: Do NOT use plain frosting, bowls or jars. Each photo must show the
frosting generously spread/swirled on an actual brownie piece.

Use the SAME brownie shape, camera angle, lighting and background for all seven
so they look consistent. Recommended ~600×480px.

Filenames:
- dark-ganache.jpg
- milk-ganache.jpg
- white-ganache.jpg
- nutella.jpg
- biscoff.jpg
- pistachio.jpg
- peanut-butter.jpg

Until a file exists, an on-brand placeholder (distinct colour per frosting) is
shown automatically. Paths can be changed in `js/script.js`.
