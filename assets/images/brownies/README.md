# Brownie product photos

Drop your real brownie photographs here using these exact filenames so the
site picks them up automatically (JPG recommended, ~800×640px, same crop):

- hero.jpg               → homepage hero image
- about.jpg              → About section image
- fudge-classic.jpg
- choco-melt.jpg
- midnight-snow.jpg
- midnight-melt.jpg
- midnight-elegance.jpg
- choco-fusion.jpg
- choco-trio.jpg
- choco-overload.jpg

Until a file exists, an on-brand placeholder is shown automatically.
To use different paths/filenames, edit the `image` values in `js/script.js`.
