# Choco chip photos

Shown on the Choco Chips step. Recommended ~1000px wide JPG, same look as the
frosting photos.

Filenames and what they are called on the site:
- dark-chips.jpg  → Midnight Bites (Dark Chocolate Chips)
- milk-chips.jpg  → Cocoa Drops (Milk Chocolate Chips)
- white-chips.jpg → Snow Pearls (White Chocolate Chips)

Names and descriptions are set in `js/script.js` (`CHIPS`).
